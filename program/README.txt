================================================================================
  ✂ FileSplitter — Разрезание и склеивание больших файлов
  Версия 1.1
================================================================================

Утилита режет большой файл на части и склеивает их обратно.

ГЛАВНОЕ: части — это ЧИСТЫЕ БАЙТЫ. Их можно склеить БЕЗ нашей программы:

  Linux / macOS:  cat file.mp4.* > file.mp4
  Windows:        copy /b file.mp4.001+file.mp4.002 ... file.mp4
  7-Zip:          правый клик на .001 → «Извлечь»

Ваши данные НЕ ЗАВИСЯТ от программы. Скрипт восстановления создаётся
автоматически.

  ЧТО ЭТО
================================================================================

Три задачи, которые решает утилита.

1. РАЗРЕЗАТЬ БОЛЬШОЙ ФАЙЛ
   Файл больше лимита почты, мессенджера или флешки с FAT32 (4 ГБ на файл)?
   Загрузка в Telegram (ограничение на размер файлов 2 ГБ), в MAX
   (там 4 ГБ). Утилита разрежет его на части нужного размера.

2. СКЛЕИТЬ ОБРАТНО
   Собрал все части в одну папку → утилита проверит целостность набора
   и склеит в исходный файл.

3. ПРОВЕРИТЬ НАБОР
   Не склеивая — проверить, что все части на месте, размеры совпадают,
   SHA-256 сходится, сумма размеров соответствует оригиналу.

================================================================================
  ЧЕСТНО О ВОЗМОЖНОСТЯХ
================================================================================

1. ЧАСТИ — ЭТО ЧИСТЫЕ БАЙТЫ
   Утилита НЕ добавляет никаких заголовков в файлы частей.
   file.mp4.001 — это первые N байт file.mp4.
   file.mp4.002 — следующие N байт. И так далее.

   Это сделано специально. Если FileSplitter исчезнет — файл можно
   склеить стандартными средствами.

2. СОВМЕСТИМОСТЬ С 7-ZIP, HJSPLIT, SPLIT / CAT
   Формат .001, .002, .003 — стандарт для многотомных наборов.
   7-Zip его распознаёт и может извлечь. split и cat в Linux работают
   с этим форматом нативно.

3. ПРОГРАММА НЕ ШИФРУЕТ И НЕ СЖИМАЕТ
   Это не архиватор. Если нужна защита — используйте 7-Zip с паролем.
   Если нужно сжатие — тоже 7-Zip. FileSplitter только режет.

4. ПРОВЕРКА SHA-256 — ОПЦИОНАЛЬНО
   SHA-256 на большом файле (несколько ГБ) может занять минуты. Поэтому
   по умолчанию выключено. Если важна целостность — включите галочку
   перед разрезанием.

  ВКЛАДКА «РАЗРЕЗАТЬ»

ФАЙЛ
  Кнопка «Обзор» — выбрать файл. Под полем показано: имя и размер.

РАЗРЕЗАТЬ
  Два режима — переключаются радиокнопками.

  По размеру:
    - Поле размера (например, 100)
    - Единица измерения: Б / КБ / МБ / ГБ
    - Каждая часть — ровно N, кроме последней

  На N частей:
    - Поле числа частей (например, 10)
    - Файл делится на N частей равного размера
    - Последняя может быть чуть меньше (округление вверх)

КУДА
  Папка назначения. По умолчанию — рядом с исходником: <имя_файла>_parts.

  ВАЖНО: папка автоматически подставляется при смене файла, но только
  если вы не редактировали её вручную. Как только вы ввели свой путь
  или нажали «Обзор» — автозаполнение отключается.

  ВКЛАДКА «ПРОВЕРИТЬ»

Сканирует папку и проверяет целостность набора БЕЗ склейки.

ЧТО ПРОВЕРЯЕТСЯ

ПОЧЕМУ С ВЕДУЩИМИ НУЛЯМИ
  Лексикографическая сортировка:
    video.mp4.001, video.mp4.002, video.mp4.010
    Правильный порядок — cat video.mp4.* > video.mp4

  Без нулей (video.mp4.1, video.mp4.10, video.mp4.2) — сортировка
  сломалась бы.

ЕСЛИ ЧАСТЕЙ > 999
  Автоматически используется 4 знака: video.mp4.0001. Так же работает.

ЗАЩИТА ОТ СМЕШИВАНИЯ
  При сканировании папки утилита проверяет, что все части принадлежат
  одному набору. Если в папке лежат file1.mp4.001 и file2.mp4.001 —
  будет ошибка с предложением разложить по отдельным папкам.

================================================================================
  ВОССТАНОВЛЕНИЕ БЕЗ ПРОГРАММЫ
================================================================================

Файлы частей — чистые байты. Склеить можно без FileSplitter.

LINUX / MACOS

  cd папка_с_частями
  cat video.mp4.* > video.mp4

  Все файлы video.mp4.001, video.mp4.002, … склеятся в video.mp4.

WINDOWS (CMD)

  cd папка_с_частями
  copy /b video.mp4.001+video.mp4.002+video.mp4.003 video.mp4

  Если частей много, перечислите все через +. Или используйте restore.bat.

7-ZIP

  1. Правый клик на video.mp4.001
  2. «7-Zip» → «Извлечь»
  3. Получите исходный файл

================================================================================
  СКРИПТЫ ВОССТАНОВЛЕНИЯ
================================================================================

Если галочки «Создать restore.sh» и «Создать restore.bat» были включены —
в папке с частями появятся два скрипта. Просто запустите нужный:

  bash restore.sh

или двойной клик по restore.bat.

RESTORE.SH (LINUX / MACOS)

  #!/bin/bash
  # Восстановление файла: video.mp4
  # Создано: 2026-10-14 12:30:45
  # Частей: 11
  # Всего: 1.07 ГБ

  set -e
  cd "$(dirname "$0")"

  PARTS=(
      "video.mp4.001"
      "video.mp4.002"
      "video.mp4.003"
      …
  )

  echo "Склеиваю ${#PARTS[@]} частей в video.mp4..."
  cat "${PARTS[@]}" > "video.mp4"
  echo "Готово: video.mp4"

  EXPECTED_SHA="3f7c...a9b2"
  if [ -n "$EXPECTED_SHA" ]; then
      echo "Проверяю SHA-256..."
      ACTUAL_SHA=$(sha256sum "video.mp4" | awk '{print $1}')
      if [ "$EXPECTED_SHA" = "$ACTUAL_SHA" ]; then
          echo "✅ SHA-256 совпал"
      else
          echo "❌ SHA-256 НЕ совпал — файл повреждён!"
          exit 1
      fi
  fi

RESTORE.BAT (WINDOWS)

  @echo off
  chcp 65001 >nul
  REM Восстановление файла: video.mp4
  REM Создано: 2026-10-14 12:30:45
  REM Частей: 11

  cd /d "%~dp0"

  echo Склеиваю 11 частей в video.mp4...
  copy /b video.mp4.001+video.mp4.002+...+video.mp4.011 "video.mp4" >nul
  if %ERRORLEVEL% NEQ 0 (
      echo ❌ Ошибка склейки
      pause
      exit /b 1
  )
  echo Готово: video.mp4

  REM Проверка SHA-256 (если считался)
  set EXPECTED_SHA=3f7c...a9b2
  if not "%EXPECTED_SHA%"=="" (
      echo Проверяю SHA-256...
      for /f "delims=" %%a in ('powershell -NoProfile -Command "(Get-FileHash -Algorithm SHA256 -LiteralPath 'video.mp4').Hash"') do set ACTUAL_SHA=%%a
      if /i "%EXPECTED_SHA%"=="%ACTUAL_SHA%" (
          echo ✅ SHA-256 совпал
      ) else (
          echo ❌ SHA-256 НЕ совпал
          echo    Ожидалось: %EXPECTED_SHA%
          echo    Получено:  %ACTUAL_SHA%
          pause
          exit /b 1
      )
  )

  pause

Скрипты не зависят от FileSplitter. Никакого Python, только bash / cmd
и встроенный PowerShell для проверки SHA-256 в Windows.

  МАНИФЕСТ
================================================================================

Файл <имя>.manifest.json рядом с частями. Содержит:

  {
    "version": 1,
    "original_name": "video.mp4",
    "original_size": 1073741824,
    "original_sha256": "3f7c...a9b2",
    "total_parts": 11,
    "part_size": 104857600,
    "last_part_size": 52428800,
    "created": "2026-10-14T12:30:45",
    "parts": [
      {"num": 1, "name": "video.mp4.001", "size": 104857600, "sha256": "..."},
      {"num": 2, "name": "video.mp4.002", "size": 104857600, "sha256": "..."},
      …
    ]
  }

ЧТО ДАЁТ МАНИФЕСТ
  - Восстановление имени — если пользователь переименовал часть в chunk1,
    имя оригинала восстанавливается
  - Проверка целостности — какая именно часть отсутствует или повреждена
  - SHA-256 — для проверки после склейки

ЕСЛИ МАНИФЕСТА НЕТ
  Утилита определит части по именам (.001, .002, …) и склеит без проверок.
  Тоже работает.

ЕСЛИ МАНИФЕСТ ПОТЕРЯН
  Утилита не найдёт его — скажет «по именам частей». Это не ошибка,
  просто без проверок.

ЕСЛИ В ПАПКЕ НЕСКОЛЬКО МАНИФЕСТОВ
  Утилита скажет «неоднозначно». Выберите папку с одним набором частей.

================================================================================
  СОХРАНЕНИЕ SHA-256
================================================================================

По умолчанию выключено — на больших файлах (несколько ГБ) занимает минуты.

КОГДА ВКЛЮЧАТЬ
  - Передача важных данных (архив, база, бэкап)
  - Долгое хранение — чтобы через год проверить, что не побилось
  - Если сомневаетесь в целостности дисков

ЧТО СЧИТАЕТСЯ
  - SHA-256 каждой части — при разрезании
  - SHA-256 оригинала — либо при разрезании (пересчёт), либо при склейке

ПРОВЕРИТЬ ВРУЧНУЮ

  Linux:    sha256sum video.mp4
  Windows:  certutil -hashfile video.mp4 SHA256
            (или в PowerShell: Get-FileHash -Algorithm SHA256 video.mp4)

  Сравнить с original_sha256 из манифеста.

================================================================================
  ЧАСТЫЕ ВОПРОСЫ
================================================================================

В: Если я потеряю FileSplitter, смогу склеить файлы?
О: Да. Части — чистые байты. Способы:
   1) cat video.mp4.* > video.mp4 (Linux / macOS)
   2) copy /b video.mp4.001+video.mp4.002 ... video.mp4 (Windows)
   3) 7-Zip: правый клик на .001 → «Извлечь»
   4) restore.sh / restore.bat из папки с частями
   Ваши данные не зависят от программы.

В: Что если файл частей повреждён?
О: Если был манифест с SHA-256 — утилита при проверке скажет, какая
   именно часть не совпала. Если манифеста не было — размер покажет
   проблему (если часть обрезана). При склейке без манифеста —
   повреждение не будет замечено, только размер итогового файла
   может отличаться.

В: Почему части называются .001, .002, а не .part1of10?
О: .001, .002 — стандарт, совместимый с 7-Zip, HJSplit, split / cat.
   .part1of10 — не совместим ни с чем, cat его не поймёт без sort -V.

В: Как разрезать на части, чтобы каждая влезла в почту?
О: Ограничение почты обычно 20–25 МБ. Установите размер 20 МБ.
   Учтите: некоторые почты блокируют вложения .001 — переименуйте
   в .zip перед отправкой или используйте облако.

В: Файл больше 4 ГБ на флешке FAT32 — не скопируется.
О: Разрежьте на части по 3 ГБ, скопируйте все на флешку. На другой
   стороне — склейте.

В: SHA-256 — это обязательно?
О: Нет, по умолчанию выключено. Включайте, когда важна целостность.
   На больших файлах замедляет работу примерно в 2 раза.

В: Что делать, если после склейки SHA-256 не совпал?
О: Одна из частей повреждена. Утилита предложит УДАЛИТЬ повреждённый
   файл — согласитесь, чтобы не путаться. Затем откройте вкладку
   «Проверить» — утилита покажет, какая именно часть не совпала.
   Перекачайте/перекопируйте эту часть. Если не помогает — источник
   повреждён. Битый файл по факту может сохранять свои функции - проверьте,
   может повезет.

В: Можно ли разрезать папку?
О: Нет. Только один файл. Для папки: сначала 7-Zip в архив,
   потом разрезать архив.

В: Части больше 999 — что будет?
О: Автоматически будут 4 знака в номере (video.mp4.0001 …
   video.mp4.1234). Склейка через cat работает.

В: Можно ли поменять размер части после разрезания?
О: Нет. Размер фиксирован при разрезании. Если нужно другой —
   пересоздайте.

В: Удалить исходник — опасно?
О: Галочка по умолчанию выключена. Если включите — появится диалог
   подтверждения, а исходник удалится только после успешного
   разрезания. Убедитесь, что части записались корректно.

В: Почему restore.bat не работает на моём компьютере?
О: Проверьте:
   - Кодировка файла — UTF-8 (или CP866 для старой Windows)
   - chcp 65001 в начале скрипта — устанавливает UTF-8
   - PowerShell должен быть доступен (Windows 7 SP1 и новее)
   - Если файл в C:\Program Files\ — нужны права админа

В: Где хранятся настройки?
О: См. раздел «Настройки».

В: Утилита отправляет данные в интернет?
О: Нет. Всё работает локально.

В: При запуске появляется предупреждение антивируса.
О: Некоторые антивирусы настороженно относятся к новым исполняемым
   файлам без цифровой подписи. Это нормально для небольших утилит.
   Добавьте файл в исключения или запустите «Разрешить».
